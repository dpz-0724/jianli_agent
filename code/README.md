# 云只智联 · 候选人筛选排序工具

基于对原软件 `云只_智联 4.3.8.exe`（VMProtect 加壳、易语言编写）的逆向，
实现的一个**面向智联招聘的候选人搜索 + 筛选 + 排序桌面工具**。

## 它能做什么

登录智联招聘后，输入 **关键词 / 岗位 JD / 企业筛人条件**，自动抓取候选人池，
并按综合匹配分**从高到低排序**，帮你快速锁定最合适的候选人。

- 登录智联招聘（扫码）
- **JD 智能解析**：粘贴岗位描述，自动拆出「硬性要求（学历/经验/地点）vs 加分项（技能/优先项）」，一键带出筛选条件
- 关键词 + 岗位 JD 输入 → 自动提取技能关键词（词典 + 词边界匹配）
- 筛人条件：学历 / 性别 / 年龄 / 经验 / 活跃度 / 工作地点
- 抓取候选人池 → 综合打分排序 → 排序列表 + 导出 CSV
- **候选人对比**：Ctrl/Shift 勾选 2-3 人并排对比简历要点，一键标「★最匹配」
- 跟进工作流：待联系/已联系/已约面试/不合适，双击看详情
- 采集微信 / 手机号（打招呼后）
- **演示数据模式**：无账号一键载入 40 个模拟候选人体验全流程

## 排序模型（0~100 分）

| 维度 | 分值 | 说明 |
|---|---|---|
| 关键词匹配 | 40 | 关键词 + JD 提取词，在候选人简历文本中的命中率 |
| 条件符合度 | 35 | 学历10 + 经验8 + 地点7 + 年龄5 + 性别5 |
| 活跃度 | 25 | 在线25 / 刚刚活跃20 / 今日15 / 本周10 / 本月5 |

## 快速使用

已打包好的独立程序（无需装 Python）：

```
dist\云只智联候选人筛选排序工具.exe
```

源码运行（需 Python 3.10+）：

```bash
run.bat          # 一键运行（自动装 playwright + chromium）
```

使用流程（4 步）：

1. **搜索获客**页 → 点「打开智联招聘（扫码登录）」
2. 填 **关键词**（如 `Java 销售`）和 **岗位 JD**（粘贴岗位描述）
3. **筛选条件**页 → 勾选学历/年龄/经验/活跃度/地点
4. 在智联招聘浏览到候选人列表页 → 回软件点「**抓取并排序**」→ 到 **候选人池** 页看排序结果

## 目录结构

```
app.py           桌面程序主入口（tkinter GUI，5 个页签）
code/
├─ matcher.py     JD 关键词提取 + 候选人打分排序引擎
├─ jd_parser.py   JD 智能解析（硬性要求 vs 加分项 → 自动带出筛选）
├─ demo_data.py   演示数据生成器（无账号体验）
├─ searcher.py    浏览器抓取候选人卡片（字段 + 活跃度解析）
├─ bot.py         Playwright 控 Chrome（真实 DOM 选择器）
├─ db.py          SQLite 数据层（候选人池 / 简历 / 去重 / 导出）
├─ scripts.py     话术模板 + 关键词过滤引擎
├─ api_client.py  原软件云端 API 封装（18 端点，仅供参考）
└─ auth.py        原软件账号/设备/卡密（已从 GUI 移除）
run.bat           一键运行
build.bat         打包 exe（PyInstaller）
test_flow.py      端到端流程测试
```
