# V0.9.1 产品化说明

## 产品定位

V0.9.1 聚焦一个可验收闭环：招聘人员登录智联、创建并确认岗位标准，系统在受控浏览器中执行搜索，候选人按页安全入池、去重和评估，最终由招聘人员复核和跟进。

它不是无人值守的自动录用 Agent，不承诺规避平台验证，也不替代招聘判断。

## 产品状态

当前为 `Pilot Candidate`：

- 代码级数据正确性门禁已经建立；
- Windows/Linux 单元测试与 Qt 桌面测试已建立；
- 真实智联账号、干净客户机、平台规则、签名和两周运行仍需现场完成；
- 未完成现场门禁前不得标记为正式商用版。

## 用户流程

1. 打开工作台并验证智联登录；
2. 创建岗位；
3. 填写结构化学历、经验、地点、必须能力、加分能力和 JD；
4. 招聘人员确认岗位标准；
5. 配置搜索页数、人数上限和浏览器；
6. 启动可视化搜索；
7. 每页候选人安全入库后推进检查点；
8. 遇到登录、验证码或特殊页面时暂停并人工接管；
9. 恢复任务时从最近已提交页继续；
10. 招聘人员处理去重、评估、负责人、备注和跟进。

## 平台召回与本地评估边界

当前版本只自动将“智联搜索词”输入平台搜索框。

以下结构化条件用于候选人入池后的本地评估：

- 学历；
- 经验；
- 地点；
- 必须能力；
- 加分能力。

产品界面必须明确显示该边界，避免用户误以为工作台已经设置了智联网页中的所有筛选器。后续只有在真实页面适配和验收完成后，才能将某个字段标记为“平台筛选已应用”。

## 招聘人员确认优先级

规则优先级：

```text
招聘人员结构化确认
> 招聘人员明确不限或清空
> JD 自动解析建议
```

搜索关键词只负责召回和岗位标题匹配，不自动成为必须能力。

## 逐页持久化

任务每完成一页即提交：

- 候选人主身份；
- 身份别名；
- 候选人快照；
- 岗位候选人关系；
- 评估；
- 页面检查点。

只有提交成功才更新 `last_page`。中断恢复以已提交页为准，而不是以浏览器走到的页面为准。

## 候选人身份

身份来源包括：

| 身份 | 置信度 | 用途 |
|---|---:|---|
| 平台 UID | 最高 | 精确匹配 |
| 候选人专属来源身份 | 高 | 精确匹配 |
| 精确字段指纹 | 中高 | 兼容无 UID 场景 |
| 稳定签名 | 低 | 候选重复线索 |

产品支持人工合并误拆分候选人。合并前自动备份数据库，并保存操作人和审计记录。疑似误合并时使用合并前备份恢复；V1.0 前仍需设计一键拆分能力。

## 评估有效性

评估绑定岗位标准和引擎版本。候选人主资料晚于评估时间时，旧结果自动回到“信息待核验”，避免页面显示新简历却继续使用旧结论。

## 浏览器支持矩阵

| 运行时 | 支持级别 | 说明 |
|---|---|---|
| 工作台 Chromium | 完整支持 | 与固定 Playwright 版本一同构建 |
| Microsoft Edge Stable | 备用支持 | `msedge` channel |
| Google Chrome Stable | 备用支持 | `chrome` channel |
| 自定义 Chromium | 高级模式 | 仅受控客户环境 |
| 360 / 搜狗 / QQ | 不支持 | 未纳入兼容测试 |
| Firefox / WebKit | 不支持 | 适配器仅验证 Chromium 系列 |

## Sidecar 浏览器

工作台与浏览器采用左右分屏而非强行嵌入：

- 保留完整 Playwright 协议；
- 用户能观察真实页面；
- 登录、验证码和弹窗可人工处理；
- 浏览器失效时可独立重建；
- 来源页面复用同一登录 Profile。

## 数据与备份

- SQLite WAL、外键和显式事务；
- V1/V2 → V3 增量迁移；
- SQLite Online Backup；
- 完整性检查；
- 恢复前自动备份；
- 原子替换；
- 候选人合并前自动备份；
- 当前 Windows 用户写入操作人字段。

## 发布策略

正式构建采用 PyInstaller `onedir`，包含 Python、PySide6、Playwright 和匹配 Chromium。GitHub `Package RC` 工作流生成可追踪的 Windows RC 构建产物。

V0.9.1 尚未实现自动更新服务。Pilot 必须使用版本化发布包，升级前备份数据库，并保留上一版程序和回滚说明。

## 现场验证

必须执行：

- 三台干净 Windows 客户机；
- 授权账号不少于 20 次真实搜索；
- 浏览器关闭、断网、应用强退和保存失败注入；
- 逐页恢复零丢失验证；
- UID、同名和跨岗位去重验证；
- 200 条黄金样本；
- 20 轮备份恢复；
- 两周客户连续使用；
- 平台规则、数据授权、保存期限和知识产权审查。
