# 数据与安全基线

## 默认原则

- 本地优先：候选人数据默认保存在用户设备。
- 最小必要：评估输入不使用年龄、性别、电话和微信。
- 人工决定：系统不自动作出录用或淘汰结论。
- 可追溯：保存评估版本、人工覆盖理由和导出记录。

## 本地敏感资产

```text
%LOCALAPPDATA%\RecruitmentWorkbench\workbench.db
智联浏览器 profile / Cookie
导出的 CSV
失败诊断包中的页面 HTML 和截图
```

这些内容不得提交 Git、发送到公共群组或用于未经授权的用途。

## 交付前检查

- 客户明确授权使用招聘账号与候选人数据。
- 设置数据保存期限和删除责任人。
- Windows 账号启用登录密码与磁盘加密。
- 导出文件按客户制度存放，使用后及时删除。
- 诊断包可能包含候选人页面内容，发送给技术支持前需脱敏。

## 尚未实现

V1 尚未内置数据库字段级加密、企业统一身份认证和多租户权限。需要这些能力的客户不得直接使用当前版本作为 SaaS。
