# 数据与安全基线

## 适用范围

V0.9.1 Pilot Candidate 仅适用于：

- 单个客户；
- 单个 Windows 用户；
- 单台受控电脑；
- 客户本人授权的智联招聘账号；
- 人工确认岗位标准和候选人决定。

当前版本不是多租户 SaaS，不支持多人同时操作一个数据库。

## 默认原则

- **本地优先**：候选人数据默认保存在客户设备；
- **最小必要**：自动评估不使用年龄、性别、电话和微信；
- **人工决定**：系统不自动作出录用或淘汰结论；
- **可追溯**：保存岗位版本、评估版本、人工理由、导出和合并记录；
- **可恢复**：候选人合并和数据库恢复前自动创建备份；
- **操作归属**：当前 Windows 用户写入确认、复核、跟进、导出和审计字段。

## 本地敏感资产

```text
%LOCALAPPDATA%\RecruitmentWorkbench\workbench.db
%LOCALAPPDATA%\RecruitmentWorkbench\browser_profiles
%LOCALAPPDATA%\RecruitmentWorkbench\backups
%LOCALAPPDATA%\RecruitmentWorkbench\diagnostics
客户导出的 CSV
```

浏览器 Profile 可能包含登录 Cookie；数据库、备份、CSV、页面 HTML、截图和 Trace 可能包含候选人信息。

这些内容不得：

- 提交到 Git；
- 发送到公共群组；
- 上传到未经客户批准的网盘；
- 用于招聘目的之外的处理；
- 与无权限人员共享。

## 客户机要求

- Windows 账号必须启用密码；
- 建议启用 BitLocker 或等效磁盘加密；
- 禁止多人共用同一 Windows 账号；
- 数据目录只授予当前用户和受控管理员权限；
- 企业安全软件应将发布程序列入正式审批流程，而不是临时关闭防护；
- 浏览器 Profile 不得复制给其他电脑或账号。

## 备份与恢复

- 备份使用 SQLite Online Backup API；
- 备份完成后执行完整性检查；
- 恢复前自动备份当前数据库；
- 损坏备份必须拒绝恢复；
- 候选人合并前自动备份；
- 备份保留位置和期限由客户数据责任人确认；
- 备份文件与生产数据库按同等级别保护。

## 诊断包

诊断包可能包含：

- 当前页面 URL；
- 页面截图；
- HTML；
- Playwright Trace；
- 错误堆栈和任务参数。

外发技术支持前必须：

1. 由客户数据责任人批准；
2. 检查并遮盖候选人姓名、联系方式和简历内容；
3. 使用客户批准的传输渠道；
4. 记录接收人和删除时间；
5. 问题关闭后按约定删除。

## 数据权利与删除

Pilot 前必须确认：

- 数据处理目的；
- 候选人数据来源；
- 保存期限；
- 导出权限；
- 删除责任人；
- 客户收到删除或更正请求时的处理流程；
- 卸载软件后是否保留本地数据。

当前应用不会在卸载时自动删除数据库和浏览器 Profile，避免误删。正式退出 Pilot 时必须由客户明确选择保留、归档或删除。

## 平台与账号边界

- 只使用客户授权账号；
- 不绕过验证码、账号限制或平台风控；
- 遇到验证时暂停并人工接管；
- 不承诺无限搜索或规避平台配额；
- 不将自动化稳定性建立在伪造 User-Agent 或规避检测参数上；
- Pilot 前完成平台服务规则和账号授权审查。

## 尚未实现

当前版本尚未内置：

- 数据库字段级加密；
- 企业统一身份认证；
- 角色权限；
- 多租户隔离；
- 集中式密钥管理；
- 远程设备吊销；
- 自动数据保留和删除策略；
- 安装包代码签名。

需要以上能力的客户不得将当前版本直接作为多人共享系统或 SaaS 使用。

## Pilot 安全门禁

- [ ] 客户账号与候选人数据授权书面确认
- [ ] Windows 账号和磁盘加密确认
- [ ] 数据保存期限与删除责任人确认
- [ ] 备份存储位置确认
- [ ] 诊断包脱敏与外发流程确认
- [ ] 平台规则审查
- [ ] 知识产权和代码来源审查
- [ ] 发布包签名计划确认
