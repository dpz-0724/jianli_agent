# V1 现场验收方案

## A. 安装与启动

1. 在干净 Windows 电脑安装并启动；
2. 新建岗位、关闭应用、重新打开，岗位数据仍存在；
3. 日志目录和数据库目录可定位；
4. 应用退出后浏览器工作线程能够关闭。

## B. 岗位隔离

1. 创建“Java 工程师”和“销售经理”两个岗位；
2. 分别导入或搜索候选人；
3. 修改 Java 岗位画像并重新评估；
4. 销售岗位的候选人、评估、阶段和统计不得变化；
5. 两个岗位分别导出 CSV，内容不得串岗。

## C. 评估正确性

黄金样本至少包含：

- 明确满足硬性条件；
- 明确学历冲突；
- 明确经验不足；
- 经验区间跨越最低要求；
- 必须技能在摘要中缺失；
- 多地点中的任一地点匹配；
- 简历字段缺失。

验收规则：

- 缺失信息不得自动判定为 CONFLICT；
- 经验 `1-3年` 对“至少3年”必须为 REVIEW；
- 年龄、性别变化不得影响评估；
- 每个结论必须显示可读依据。

## D. 智联自动化

使用授权招聘账号连续执行不少于 10 次搜索：

1. 首次未登录时进入 NEED_LOGIN；
2. 完成登录后可继续同一任务；
3. 登录态可在应用重启后复用；
4. 搜索、翻页和候选人解析正常；
5. 候选人再次出现时更新最新资料并保留快照；
6. 页面异常、网络中断或浏览器关闭时生成诊断包；
7. 重置浏览器后能够重新运行。

## E. 人工复核闭环

1. 修改招聘阶段；
2. 填写负责人、备注和下次跟进；
3. 写入人工复核决定及理由；
4. 关闭并重启应用后记录仍存在；
5. 导出结果包含评估依据和人工阶段。

## F. 数据治理

现场确认：

- 候选人数据保存位置；
- 谁可以访问本机账号；
- 导出文件的保存责任；
- 数据保存期限；
- 项目结束后的删除方式；
- 浏览器登录态的保护和退出方式。

## 发布结论

只有 A-F 全部通过，才允许标记为 `V1.0 Pilot`。未完成真实智联验收时只能标记为 `V1.0 RC`。
