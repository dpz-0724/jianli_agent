# V0.9 界面使用说明

## 岗位工作台

- “解析并保存草稿”只保存系统建议；
- “确认岗位标准”是正式门禁；
- 已确认后才启用“开始智联搜索”；
- 修改任意岗位字段后，岗位重新变为草稿。

## 候选人收件箱

- 建议优先查看：当前资料未发现明确冲突；
- 信息待核验：关键资料缺失或区间无法确认；
- 明确冲突：存在可核验的学历、经验等规则冲突；
- 双击候选人进入人工复核，系统评估不等于最终招聘结论。

## 自动化任务

- 显示浏览器：把受控浏览器带到前台；
- 暂停：在下一个安全检查点停止点击；
- 人工接管：暂停并显示浏览器；
- 继续：人工处理完成后恢复；
- 停止任务：安全取消并保留页码检查点；
- 从检查点恢复：从上次完成页的下一页继续搜索。

## 系统与数据

- 默认选择工作台 Chromium；
- Edge / Chrome 用于客户环境备用；
- 清除登录状态会删除受控浏览器 Cookie 和缓存；
- 数据库备份可用于升级、迁移和现场恢复；
- 诊断目录可能包含页面内容，应限制访问并定期清理。
